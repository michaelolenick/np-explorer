Privacy

What we don't do

  • No accounts.
  • No tracking or analytics.
  • No cookies.
  • No ads.

What the server logs

The web server keeps standard access logs: IP address, time, the page requested (which includes any name you search for, since searches are part of the address) and your browser's user agent. Logs are deleted after 14 days. They are used only to keep the site running and stop abuse.

Where the data comes from

Everything shown about people and organizations comes from public IRS filings. See Data.

Ask in plain English

When you use Ask, the text of your question is sent to Anthropic's API (the Claude language model) so it can pick which of our searches to run. Nothing else about you is sent: no IP address, no cookies, no account. The answer itself comes from our database. We keep recent questions in memory for a day so repeats are fast, and don't log them.

The contact form

The contact form sends an email to us. Nothing is kept beyond that email: no database, no mailing list. Your IP address is used only for rate limiting and spam control; the email we receive shows only the first part of it (your network, not your address). If our mail service is down, the message is held on the server until we can read it, then deleted.

Corrections

If something shown here is wrong, use the contact form or email corrections@strategystudio.org with the page address and what is wrong. Removal requests go to the same place. If the error is in the filing itself, the organization has to amend its return with the IRS; we can note the problem in the meantime.
