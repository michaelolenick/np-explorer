MCP server

Add FURP to an AI assistant as a remote MCP server (streamable HTTP, no login):

{{ mcp_url }}
  • Claude (claude.ai and the desktop app): Settings → Connectors → Add custom connector. Name it FURP and paste the URL above.
  • Claude Code: claude mcp add --transport http furp {{ mcp_url }}
  • ChatGPT: Settings → Apps & Connectors → Advanced settings → turn on Developer mode, then Create, and paste the URL above (no authentication).
  • Cursor, VS Code and other clients: add it to the client's MCP settings, for example: 
    {"mcpServers": {"furp": {"url": "{{ mcp_url }}"}}}

JSON API

Base URL: {{ site_url }}{{ api }}. Responses are JSON; errors are {"error": "..."} with the HTTP status. The machine-readable spec is at /api/openapi.json (browsable at /api/docs).

EndpointWhat it returns
GET {{ api }}/search?q=name&type=allPeople, organizations, contractors and schools matching a name or EIN. type: all, people, organizations, contractors or schools; limit up to 25.
GET {{ api }}/people/idA person: nonprofit roles, titles and pay by year, how the records were matched, and cross-referenced records (FEC, SEC, lobbying, payroll, business registries). Takes the id, the slug or the furp.org URL.
GET {{ api }}/organizations/einA nonprofit: finances for every filing, people and pay, contractors, grants received, federal awards, lobbying and more.
GET {{ api }}/datasetsEvery dataset, its source and its page URL patterns.
GET {{ api }}/datasets/dataset?q=nameRecords in one dataset matching a name.
GET {{ api }}/leaderboards, {{ api }}/leaderboards/slug?page=1Ranked lists across the whole database.

Examples:

curl '{{ site_url }}{{ api }}/search?q=red+cross&type=organizations'
curl '{{ site_url }}{{ api }}/organizations/53-0196605'
curl '{{ site_url }}{{ api }}/datasets/lobbying?q=pfizer'

Linking to records

Every person and organization has one permanent URL: a name slug, then a stable ID, such as /org/american-national-red-cross-530196605. The ID alone also works and redirects there, so a link can be built from an EIN or a person id without knowing the slug: {{ site_url }}/org/ein, {{ site_url }}/person/id.

Rate limits

About one request a second per IP, with short bursts. Over the limit you get HTTP 429 with a Retry-After header; when the database is busy, 503 with Retry-After. Results are cached for a few minutes, so repeating a request is cheap. Need more, or the data in bulk? Email info@furp.org.

For AI crawlers

/llms.txt describes FURP for language models (/llms-full.txt has more detail), alongside the sitemap. Entity pages carry schema.org JSON-LD (Person, NGO, Corporation and others) with identifiers such as EIN and SEC CIK.
