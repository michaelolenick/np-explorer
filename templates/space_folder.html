Folder mark

The folder’s mark is the default for new uploads. A Public folder gets a page listing its Public files; files marked Private or FURP-readable stay hidden even then.

What the marks mean

  • Private: only you and super admins can open it. FURP’s own analysis does not read it.
  • FURP-readable (the default): FURP can read it and use it internally in its analysis, but never exposes it, links to it or quotes it publicly. To anyone else it looks exactly like Private.
  • Public: a stable URL anyone can open without logging in. Setting it back to Private or FURP-readable removes the URL.
