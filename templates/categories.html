Nonprofit categories

Each nonprofit gets an NTEE code (National Taxonomy of Exempt Entities): the one the IRS publishes in its Business Master File, or, where the IRS lists none, one inferred from the organization's name and Form 990 text by a small language model. Published and inferred codes are counted separately everywhere.

A caveat on the stated codes

The “published” code is whatever the IRS lists for the organization. The IRS assigns it once, when it rules on the exemption application, and rarely revisits it, so it is often stale or simply wrong. Examples from the IRS file, as published: {% for ein, name, code, label in cats.CAVEAT_EXAMPLES %}{{ name }} is coded {{ code }} ({{ label }}){% if not loop.last %}; {% endif %}{% endfor %}. All three are churches by name, which a model reading the same record calls X20 (Christianity). In a test of 500 organizations whose codes the IRS publishes, a small model reading the name and 990 text agreed with the IRS on the major group 56% of the time and on the exact code 21%; the disagreements are often the IRS code's fault, but not always. Treat every stated code, published or inferred, as a hint, not a finding. The FURP topics below come from a different source: what each organization’s own 990 text says it does.
